# Formula 1 Mark 🏎️💨

Ein Formula 1 3D-Projekt mit hochauflösenden Fahrzeugmodellen, Blender-Szenenaufbau und automatisierter Blender MCP-Integration.

## 📂 Projektstruktur

- **cars 3d/**: 3D-Modelle der Boliden (im GLB/glTF-Format):
  - ormula 1 car 3d model.glb
  - ormula one car 3d model red bull.glb
  - ace car 3d model.glb
- **ormula_1_mark.blend**: Hauptszene in Blender (5.2.1 LTS) mit strukturierter Collection-Hierarchie (COL_Vehicles, COL_Track, COL_Environment, COL_Lighting, COL_Cameras).

## 🛠️ Tech-Stack & Tools

- **Blender 5.2.1 LTS**
- **Blender MCP (Model Context Protocol)** zur KI-gestützten Szenen- und Modellierungsautomatisierung
- **Git LFS** für die Verwaltung großer 3D-Assets (.glb, .blend)
